**One addon to rule them all.** AIOStreams consolidates multiple Stremio addons and debrid services into a single, highly customisable super-addon.

---

## 📝 SYNOPSIS

AIOStreams acts as a central hub for your Stremio experience. It fetches results from all your favorite sources, then filters, sorts, and formats them according to your rules before presenting them in a single, clean list. Whether you're a casual user or a power user who wants fine-grained control, AIOStreams has you covered.

## ⚙️ ENVIRONMENT

| Variable | Description | Default |
|----------|-------------|---------|
| `SECRET_KEY` | Required 64-character hexadecimal encryption key; never replace it on upgrade | Generated by Runtipi |
| `AIOSTREAMS_AUTH` | Required instance logins as `username:password` pairs, separated by commas; these users have admin access | - |
| `ADDON_PASSWORD` | Legacy password retained for migration from versions before v2.30; not the instance login | - |
| `DATABASE_URI` | SQLite or PostgreSQL connection | `sqlite://./data/db.sqlite` |
| `TMDB_ACCESS_TOKEN` | For title matching filter | - |

## 🚀 GETTING STARTED

1. In Runtipi's app settings, set **Instance Login Credentials** in `username:password` format. Choose your own credentials; there is no default login. Do not share these credentials or your installation URLs.
2. Open the app at your configured domain and navigate to `/stremio/configure`. Sign in with the instance credentials when prompted.
3. Enable addons, add your service API keys, and configure filters.
4. Open **Save & Install**. Under **Create Configuration**, choose a separate configuration password and click **Create**. Save both the generated UUID and your chosen password securely; the documentation warns that lost credentials cannot be recovered.
5. Use the installation options to add your configuration to Stremio. Export a configuration backup and store it securely.

Instance credentials control access to this installation and its admin dashboard. The configuration UUID and password identify one saved addon configuration. Neither is the encryption **Secret Key** or the legacy **Addon Password**.

### Upgrading From Versions Before v2.30

Back up the app's persistent data and retain the existing **Secret Key** before updating. Database migrations run automatically on startup.

Set **Instance Login Credentials** before starting the updated app. Keep your previous **Addon Password** unchanged for at least the first successful startup so AIOStreams can migrate existing configurations. After migration, that field can be cleared. Do not rotate the config access key unless you intend to re-save existing configurations.
